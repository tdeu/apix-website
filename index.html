Hedera in your app. One command.

APIX writes working token, consensus, contract and wallet code into your app. It builds. It runs on Hedera mainnet.

bash v2.1.0 
npm install -g apix-ai

v2.1.0 release pending: the current npm version is 2.0.3.

One command per feature

Pick what you need. APIX writes the code and installs the packages.

Tokens

apix add hts

Create, mint and transfer tokens through ready-made API routes.

Consensus

apix add consensus

Write ordered, timestamped messages to an HCS topic.

Smart contracts

apix add smart-contract

Deploy Solidity and call it from your server code.

Wallet

apix add wallet

Connect HashPack or Blade from the browser.

Built safe by default

  • Keys never touch the browser. Hedera modules are server-only; a client import fails the build.
  • Secrets stay masked in console output, logs and errors.
  • Mainnet spends ask first. The CLI won't spend real HBAR without a yes.
  • 246 tests, 0 high or critical advisories in production dependencies.

Quick start

About 4 minutes from apix add hts to a successful build.

1

Install

bash v2.1.0 
npm install -g apix-ai

v2.1.0 release pending: the current npm version is 2.0.3.

2

Add a free testnet account (portal.hedera.com)

.env.local 
HEDERA_NETWORK=testnet
HEDERA_ACCOUNT_ID=0.0.xxxxx
HEDERA_PRIVATE_KEY=302e...
3

Add Hedera to your app

bash 
apix add hts

Optional AI helpers: explain, chat, recommend. Bring your Anthropic or OpenAI key.
