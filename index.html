Working Hedera integrations for Next.js

APIX is a CLI that adds Hedera integrations (tokens, consensus, smart contracts, wallet) to a Next.js app, with generated code that builds and runs on testnet.

v2.1.0: rebuilt and verified on Hedera testnet.

Powered by:
ℏ Hedera
TS TypeScript
N Next.js
Anthropic Claude / OpenAI (optional AI features)

Adding Hedera to an app takes time

Wiring Hedera into a web app takes time and specialist knowledge

Several services to learn

Tokens, consensus topics and smart contracts each have their own transactions and SDK calls

Keys must stay on the server

The operator key signs transactions, so it has to be kept out of browser code

Boilerplate before anything works

Client setup, API routes, input checks, hooks and UI all come before the first transaction

Four integrations, one command each

apix add <integration> writes the files into your project and installs their packages

Hedera Token Service

apix add hts generates 14 files: a server-side Hedera client, an htsManager module, four API routes, React hooks and components.

Routes: POST /api/tokens/create, GET /api/tokens/info, POST /api/tokens/mint, POST /api/tokens/transfer
Hooks: useTokens, useWallet
Components: TokenManager, TransactionStatus (with HashScan link), UI primitives

Hedera Consensus Service

apix add consensus (alias hcs) generates a consensusManager module and two API routes, with input checks.

POST /api/consensus/topics: create a topic
POST /api/consensus/messages: submit a message
Messages up to 1024 bytes, memos up to 100 bytes (HTTP 400 otherwise)

Smart contracts

apix add smart-contract (alias contract) generates a smartContractManager module that you call from your own server code. No routes.

deployContract: deploys Solidity bytecode (ContractCreateFlow)
executeContract: calls a function (ContractExecuteTransaction)
callContract: reads a view function (ContractCallQuery)

Wallet

apix add wallet generates browser code to connect HashPack or Blade through their browser extensions. The connected wallet is displayed and can be used as a transfer recipient; it never signs.

walletService with HashPack and Blade adapters
useWallet hook and ConnectWallet component
The browser wallet flow has not been tested end to end on testnet yet

Security

What APIX and its generated code do with your keys and your HBAR

Keys stay server-side

Generated Hedera modules start with import 'server-only', so importing them from client code fails the build. Credentials are never NEXT_PUBLIC_

Secrets masked

Secrets are masked in console output, log files and error messages

Input validation

Hedera inputs are validated before any transaction is sent

Mainnet confirmation

On mainnet, commands that spend HBAR ask for confirmation first, or need --yes

Optional AI features

Everything above works without an AI key. These commands need an Anthropic or OpenAI key

Learn and decide

apix explain, apix compare, apix recommend and apix confidence explain Hedera concepts and help you choose an integration

Generate

apix generate classifies your requirement with the AI, then writes the same files as apix add

Chat and debug

apix chat is a conversation about your Hedera project. apix debug diagnoses an issue and suggests what to try; it never changes anything

Experimental: compose

apix compose --experimental lists the files it composed, without writing them. It is hidden from --help by default

How the provider is chosen

Anthropic is used when ANTHROPIC_API_KEY is set, otherwise OpenAI when OPENAI_API_KEY is set.
Without a key, the AI commands exit with a message saying which key to set. There are no canned replies.
OpenAI support has not been verified with a live key yet.

Installation and quick start

Measured once on a laptop: about 4 minutes from apix add hts to a successful next build, plus the app's own npm install

v2.1.0 release pending: the current npm version is 2.0.3.
1

Install APIX

bash v2.1.0 
npm install -g apix-ai
2

Set up a testnet account

Get a free testnet account (account ID and DER-encoded private key) at portal.hedera.com. Keep these server-side, never NEXT_PUBLIC_.

.env 
HEDERA_NETWORK=testnet
HEDERA_ACCOUNT_ID=0.0.xxxxx
HEDERA_PRIVATE_KEY=302e...

# Optional, for the AI commands
ANTHROPIC_API_KEY=...
OPENAI_API_KEY=...
3

Add Hedera to your app

In a Next.js (App Router, TypeScript) project:

bash 
apix analyze
apix add hts
npm run dev
